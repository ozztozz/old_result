Geliştiriciler İçin REST API Dokümantasyonu
Doğrudan Veri Dönüşü (Açık Endpoint)

Herhangi bir token veya oturum açma gerekmeden bu API endpoint'ine GET veya POST istekleri gönderebilir ve doğrudan JSON formatında sporcu ID eşleşmesini alabilirsiniz.

1. GET İsteği ile Sorgulama
GET /api/sporcu-eslestir/?sporcu_adi=Efe+İŞLER&dogum_yili=2007
2. POST (JSON) İsteği ile Sorgulama
POST /api/sporcu-eslestir/
Content-Type: application/json

{
  "sporcu_adi": "Efe İŞLER",
  "dogum_yili": 2007,
  "kulup": "Enka"  // Opsiyonel
}
3. Örnek JSON Yanıtı (Tam Eşleşme)
{
  "durum": "basarili",
  "sonuc": "tam_eslesme",
  "bulunan_id": 7904,
  "sporcu": {
    "id": 7904,
    "sporcu_adi": "Efe İŞLER",
    "dogum_yili": 2007,
    "cinsiyet": "ERKEK",
    "kulup": "Enka Spor Kulübü",
    "toplam_yaris_sayisi": 34,
    "profil_url": "/sporcular/7904/"
  },
  "muhtemel_eslesmeler": []
}
