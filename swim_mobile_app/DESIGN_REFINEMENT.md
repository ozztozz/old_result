# DESIGN REFINEMENT – SOFT GLASS + AMBIENT GLASS

The current implementation is a good functional starting point, but its visual identity does not yet fully match the intended design direction.

I want you to refine the existing interface rather than redesigning the application from scratch.

The target design language is:

**SOFT GLASS + AMBIENT GLASS + COOL SOPHISTICATED**

The current screen is too flat, too conventional and too close to a standard light dashboard template.

It has good information hierarchy and readability. Preserve those strengths while significantly improving its visual character.

## 1. WHAT NEEDS TO CHANGE

### A. Background and Atmosphere

The current background is mostly flat and light grey.

Transform it into a sophisticated ambient environment.

Introduce:
- Very subtle cool-toned gradients.
- Large, soft, blurred organic shapes.
- Delicate ambient lighting.
- Abstract flowing vector curves.
- Thin contour lines with elegant compositions.
- Subtle depth between background layers.

The background should feel atmospheric, not decorative.

Do not use generic diagonal lines as the primary visual identity.

Create a more distinctive abstract visual language.

### B. Glassmorphism

The current cards look like ordinary white containers.

Make glass surfaces an actual part of the design.

Use:
- Semi-transparent surfaces.
- Frosted glass effects.
- Subtle backdrop blur.
- Delicate translucent borders.
- Soft light reflections.
- Layered surface treatments.
- Very subtle shadows.

The glass effect should be visible enough to create depth but never compromise readability.

Avoid making all cards equally transparent.

Create visual hierarchy through different surface treatments.

### C. Statistics / Hero Section

The top statistics section should become a distinctive visual element.

Improve its composition using:
- A layered glass panel.
- Ambient light behind the panel.
- Elegant numerical typography.
- Subtle vector details.
- Better visual separation between statistics.

It should feel like a premium dashboard highlight rather than a standard information card.

### D. Competition Cards

Preserve all existing competition information and functionality.

Improve the cards through:
- More sophisticated glass surfaces.
- Better spacing and typography.
- Delicate borders.
- Subtle depth.
- Better distinction between live status, competition title and supporting information.
- More refined progress indicators.

Avoid repetitive, generic white card styling.

The cards should feel integrated into the overall ambient environment.

### E. Bottom Navigation

The current bottom navigation looks too conventional.

Transform it into a refined floating glass navigation panel.

Requirements:
- Frosted translucent background.
- Subtle blur.
- Delicate border.
- Elegant active-state indicator.
- Comfortable icon and label spacing.
- Subtle floating depth.

Keep the navigation compact and usable.

## 2. COLOR IDENTITY

Use the previously defined Cool Sophisticated palette.

Primary colors:
- #DCE4E8
- #AABBC6
- #657D91
- #273746

Light theme:
- Background: #F1F4F6
- Surface: #FFFFFF
- Secondary surface: #EDF2F5
- Primary text: #273746
- Secondary text: #71808C
- Accent: #657D91

Do not make the screen excessively white or washed out.

Introduce controlled tonal contrast.

The application should feel sophisticated, not sterile.

## 3. ORIGINAL GRAPHIC LANGUAGE

This is a particularly important requirement.

I want the interface to have a recognizable visual signature.

Use custom vector graphics such as:
- Flowing organic lines.
- Concentric arcs.
- Abstract orbital compositions.
- Fine contour patterns.
- Subtle geometric intersections.

Use these elements in the hero area, selected cards and background compositions.

Do not place random decorative graphics everywhere.

Create a consistent visual language.

SVG or native vector drawing is preferred.

## 4. VISUAL HIERARCHY

The interface should have three visual layers:

Layer 1: Ambient background
- Soft gradients
- Abstract shapes
- Flowing vector details
- Atmospheric lighting

Layer 2: Glass surfaces
- Statistics panel
- Competition cards
- Search area
- Navigation panel

Layer 3: Content
- Typography
- Numbers
- Icons
- Status indicators
- Interactive controls

These layers should work together to create a refined sense of depth.

## 5. WHAT TO AVOID

Do not:
- Simply add blur to existing white cards.
- Make every element transparent.
- Add excessive gradients.
- Use strong neon colors.
- Add random decorative circles.
- Use excessive shadows.
- Make everything pill-shaped.
- Reduce text readability.
- Change the application's information architecture unnecessarily.
- Make the design more complicated than the current version.

## 6. PRESERVE EXISTING FUNCTIONALITY

This is a refinement task, not a functional rewrite.

Preserve:
- Existing competition data.
- Search functionality.
- City filters.
- Competition status.
- Statistics.
- Navigation.
- Progress indicators.
- Existing interactions.

Do not remove or rename existing functionality.

## 7. IMPLEMENTATION APPROACH

First, analyze the current screen and identify which existing components need visual refinement.

Then:
1. Improve the background and ambient layers.
2. Refine the statistics panel.
3. Redesign the competition card surfaces.
4. Improve the floating bottom navigation.
5. Introduce the abstract vector graphic identity.
6. Verify the final visual balance.

Use the existing technology stack and styling architecture.

Keep reusable styling centralized.

Avoid unnecessary dependencies and duplicated styles.

## FINAL EXPECTATION

I do not want a typical light-mode dashboard with white cards.

I want a sophisticated, atmospheric and distinctive mobile interface.

The result should combine the softness of frosted glass, the depth of ambient lighting and the elegance of abstract vector compositions.

**Make the design feel premium through depth, composition, subtle light and material quality — not through excessive decoration.**
